# Picasso releases

Windows installers and update files for Picasso. The source code is kept elsewhere.

Download the latest version from the Releases page.

## ComfyUI helper for remote downloads

`comfyui/picasso-remote` is a small ComfyUI add-on that lets Picasso download model files on a ComfyUI running on another computer, such as a Runpod pod. See [its README](comfyui/picasso-remote/README.md) for install steps.
